## AI Course Builder and Studio

Start creating courses instantly with the AI course builder. Provide a brief outline, and AI generates modules, lessons, quizzes, narration scripts, and even slides.

<Steps>
  <Step title="Generate Outline" icon="sparkles">
    Enter your course topic and target audience.

    ```
    Brief: Six-week watercolor for beginners
    Tone: Warm, practical
    ```

  </Step>
  <Step title="Build Full Course" icon="play">
    AI creates lessons, quizzes, and certificates.
  </Step>
  <Step title="Customize in Studio" icon="edit-3">
    Revise content, add videos, or regenerate sections.
  </Step>
  <Step title="Publish" icon="rocket">
    Launch to your academy domain.
  </Step>
</Steps>

<Callout kind="tip">
  Use the AI Studio for iterative improvements—regenerate specific modules without rebuilding everything.
</Callout>

## Courses, Quizzes, and Certificates

Build engaging courses with multimedia lessons, quizzes, and assignments. Issue verifiable certificates with QR codes for completion.

<Tabs>
  <Tab title="Quizzes" icon="check-circle">
    Embed quizzes after modules to reinforce learning.

````javascript
// Example quiz payload via API
POST https://api.example.com/v1/quizzes
{
  "course_id": "course_123",
  "title": "Module 1 Quiz",
  "questions": [
    {
      "type": "multiple_choice",
      "question": "What is a wash?",
      "options": ["A", "B", "C"],
      "correct": 0
    }
  ]
}
````

  </Tab>

````javascript
// Certificate verification endpoint

````

## Website Builder and Custom Domains

Design landing pages, blogs, and checkouts without code. Connect your custom domain like `academy.yourdomain.com`.

<CodeGroup tabs="JavaScript,cURL">
```javascript
// Set custom domain via API
const response = await fetch('https://api.example.com/v1/domains', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' },
  body: JSON.stringify({
    "domain": "academy.example.com",
    "academy_id": "acad_456"
  })
});
```

```bash
curl -X POST https://api.example.com/v1/domains \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"domain": "academy.example.com", "academy_id": "acad_456"}'
```
</CodeGroup>
